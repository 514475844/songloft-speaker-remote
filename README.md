# Songloft Speaker Remote · 小爱音箱遥控器

一个 Songloft 插件：把任意一台旧手机/平板变成小爱音箱的**专用遥控器**——常驻大按钮界面，直接把 Songloft 里的歌单/单曲推送到家里的小爱音箱播放。

## 功能

- 🎵 歌单 / 单曲推送到小爱音箱播放（支持「▶全碟」或点任意一首）
- ⏯ 播放 / 暂停、可拖动进度条（seek）、倍速（0.75×–2×）
- 🔊 音量调节、播放模式（顺序 / 循环 / 随机 / 单曲）
- 🌗 亮色 / 暗色主题一键切换（自动记忆）
- 📱 全设备自适应：窄屏自动换行、横屏紧凑模式、刘海安全区适配
- 🔑 插件环境下**免登录**：自动使用 Songloft 宿主注入的访问令牌

## 要求

- Songloft **2.6.3+**
- 已安装并启用官方 **「智能音箱」(miot)** 插件，且小爱音箱已在该插件中绑定
- 浏览器需能访问 Songloft 所在主机（局域网内使用）

## 安装

### 方式一：Songloft 插件商店（GitHub 发现）

1. 打开 Songloft 管理后台 → 插件 → 插件商店
2. 选择「发现源」→ 添加 GitHub 源，填入本仓库
3. 找到 **Speaker Remote**，点击安装并启用

### 方式二：手动侧载

1. 从 [Releases](../../releases) 下载最新的 `speaker-remote.jsplugin.zip`
2. Songloft 管理后台 → 插件 → 上传插件包
3. 启用后访问插件页面即可

## 使用建议（旧手机常驻遥控）

1. 旧手机连入家庭局域网
2. 浏览器打开插件页面（或 Songloft 内进入插件）
3. 「添加到主屏幕」获得全屏图标
4. 关闭自动锁屏，即为永久遥控器

## 工作原理

纯静态前端插件（无独立后端逻辑）：页面与 Songloft 同源运行，自动获取宿主注入的访问令牌后直接调用 Songloft 与智能音箱插件的 REST API，无需任何中转服务。

> 注意：小爱音箱的 MIoT 接口不支持「上一首 / 下一首」切歌，这是小米侧的限制，非本插件缺陷。

## 开发

```bash
npm install
npm run build        # 官方工具链构建（产出 dist/<entryPath>.jsplugin.zip）
node build.mjs       # 备用构建脚本（部分 Windows 环境官方 CLI 的 cpSync 会崩溃时使用）
```

构建脚本会自动计算 `entryHash` / `zipHash` 并回填到 `plugin.json`。
